# Проектирование скоринговой модели ресторана и алгоритмизация таргетирования 🥩📊

## 📌 Краткое описание проекта
Цель выпускной работы — провести комплексный разведочный анализ данных (EDA) ресторанных транзакций и выявить ключевые факторы, влияющие на маржинальность бизнеса, размер среднего чека и лояльность клиентов (выраженную в проценте чаевых). Результаты работы сформированы в виде аналитического отчета для топ-менеджмента заведения с конкретными стратегическими рекомендациями по оптимизации залов и увеличению выручки.

## 🛠 Технологический стек
* **Язык разработки:** Python 3.10
* **Библиотеки анализа:** Pandas, NumPy, SciPy (модуль `stats`)
* **Визуализация данных:** Matplotlib, Seaborn, Plotly Express
* **Математический аппарат:** Двухвыборочный T-критерий Стьюдента для независимых выборок

## 📊 Основные этапы исследования и структура работы
1. **Предобработка и валидация данных:** Очистка данных, удаление дубликатов, проверка типов. Данные признаны полностью надежными.
2. **Разведочный анализ (EDA):** Анализ распределения величины счетов и чаевых, выявление правосторонней асимметрии ("премиального хвоста").
3. **Расчет Unit-метрик:** Создание относительных показателей (`tip_percent`, `bill_per_person`).
4. **Статистическое тестирование:** Проверка гипотез о различиях в поведении дневных и вечерних когорт.
5. **Поведенческий анализ:** Изучение влияния демографии (пол) и привычек (курение) на щедрость гостей.

## 📈 Ключевые бизнес-инсайты

### 1. Критичный инсайт: «Парадокс больших компаний»
В ходе анализа была опровергнута гипотеза о том, что большие столы выгоднее для заведения. 
* При росте количества человек за столом абсолютная выручка растет, но **удельная эффективность на один стул резко падает**.
* Средний чек на одного гостя (`bill_per_person`) и маржинальность чаевых достигают пика на столах для двоих (`size=2`) и планомерно снижаются к крупным компаниям (из 5–6 человек). Крупные группы чаще заказывают комбо-плато, которые стоят дешевле в пересчете на человека, и удерживают столы значительно дольше, снижая общую оборачиваемость посадочных мест.

### 2. Математическое подтверждение разницы чеков (Анализ временных когорт)
Была проверена гипотеза об отсутствии различий в удельных расходах гостей между обедом (`Lunch`) и ужином (`Dinner`) с помощью Т-критерия Стьюдента:
* Средний чек на человека в обед: **$7.32**
* Средний чек на человека в вечернее время: **$8.11**
* **Статистические метрики:** T-статистика: `-2.1487`, **p-value: 0.0332**
* *Вывод:* Так как `p-value < 0.05`, нулевая гипотеза отвергается. Разница в чеках статистически значима. Вечерние когорты приносят заведению значимо больше прибыли на одного человека.

## 🎯 Стратегические рекомендации для менеджмента ресторана
1. **Реконфигурация посадочных зон зала:** Ресторану невыгодно держать много фиксированных столов на 6 человек. Рекомендуется использовать модульные столы-трансформеры для двоих, объединяя их под большие компании только при необходимости. Основной упор в зале нужно сделать на зоны для пар (`size=2`).
2. **Активация дневного трафика (Комбо-обеды):** Для загрузки кухни в пустующие часы `Lunch` необходимо внедрить линейку быстрых бизнес-ланчей с маржинальными мясными позициями, чтобы искусственно поднять средний чек с $7.32 до вечернего уровня.
3. **Контроль сервиса премиального сегмента:** Интерактивный анализ Plotly показал, что на чеках свыше $40 процент чаевых начинает хаотично падать (до 5.6%). Это указывает на возможные сбои в качестве обслуживания крупных столов в пиковые часы. Необходимо закрепить за ними опытных официантов.
